VIRTUAL WORKS - HEALTHCARE DATA ANALYTICS TASK 1

START HERE:
1. Extract this ZIP file.
2. Open the extracted folder in File Explorer.
3. Open Healthcare_Task1_R_Script.R in RStudio.
4. Keep the HealthcareAnalytics-main folder beside the R script.
5. Install packages once if prompted (see commented install.packages line).
6. Run the script from top to bottom.
7. Open task1_outputs/Healthcare_Task1_R_Results.xlsx for exported tables and PNG plots.

Included:
- Healthcare_Task1_R_Script.R
- Healthcare_Task1_Analysis.xlsx (initial Python-generated analysis)
- Healthcare_Task1_Report.docx
- claims_data_cleaned.csv
- Original HealthcareAnalytics-main folder with all five supplied files.

Important data limitation:
claims_data.csv has 1,000 rows and 15 columns, but no Age, Gender, Medication or Dosage fields.
The Pharma_data.csv file is a product reference, not a patient medication record.
The supplied ICD-11 reference has not been validated as the matching diagnosis code system.
Do not invent patient demographics, medication use, dosage, or disease-name mappings.
