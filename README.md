# Task 4: Adverse Drug Reaction Analysis

Data: 100 reports from user-provided `ADR_event.json` (openFDA).

Files:
- `ADR_Task4_Analysis.xlsx`: report, reaction and drug tables and frequency summaries
- `ADR_Task4_Report.docx`: methodology, results, plots and limitations
- `top_reactions.png`, `top_drugs.png`, `seriousness.png`: charts
- `ADR_event.json`: original input

**Important:** Reports are spontaneous safety reports, not verified causal relationships or drug risk estimates. Counts describe the 100 retrieved records only.
